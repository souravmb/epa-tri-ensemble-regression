# Code of Conduct

## Our Standards

This is a research repository associated with an academic submission at Amrita Vishwa Vidyapeetham. All interactions — issues, pull requests, comments, and discussions — are expected to be professional, constructive, and respectful.

Expected behaviour:

- Use clear, precise language when describing bugs, methodology concerns, or proposed improvements
- Give credit to prior work and cite sources when referencing external methods or datasets
- Accept and offer technical criticism graciously — the goal is better science, not winning arguments
- Respect that this is an academic project with a defined scope; not all contributions will be in scope

Unacceptable behaviour:

- Dismissive, insulting, or harassing comments directed at contributors or authors
- Misrepresenting results, fabricating benchmarks, or submitting code that introduces intentional data leakage
- Plagiarising third-party code or research without attribution
- Sustained off-topic discussion unrelated to the repository's research objectives

## Scope

This Code of Conduct applies to all repository spaces: issues, pull requests, commit messages, and any other communication made in the context of this project.
